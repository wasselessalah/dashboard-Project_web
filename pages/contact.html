Questions Fréquentes

Le projet utilise plusieurs APIs publiques gratuites : RandomUser API pour les utilisateurs, REST Countries pour les informations sur les pays, wttr.in pour la météo, Open Food Facts pour les produits alimentaires, et Zippopotam pour les codes postaux.

Les données sont récupérées de manière asynchrone via des requêtes AJAX ($.ajax() de jQuery). Cela permet de charger les données sans recharger la page, offrant une expérience utilisateur fluide.

Oui, le projet utilise Bootstrap 5 qui offre un système de grille responsive. L'interface s'adapte automatiquement à tous les types d'écrans : ordinateurs, tablettes et smartphones.

Les graphiques sont créés avec Chart.js, une bibliothèque JavaScript open-source. Elle permet de créer facilement des graphiques interactifs : barres, lignes, camemberts, etc.
