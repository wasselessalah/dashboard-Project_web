À propos du Projet

Découvrez notre tableau de bord dynamique basé sur des APIs publiques, un projet éducatif démontrant l'utilisation des technologies web modernes.

Description du Projet

Ce projet consiste à concevoir et développer une application web dynamique sous forme de tableau de bord (Dashboard) permettant de consommer, traiter et visualiser des données réelles issues d'APIs publiques gratuites.

L'objectif principal est d'appliquer les notions fondamentales et avancées du développement frontend, en mettant l'accent sur la manipulation des données, l'asynchronisme et la visualisation graphique.

L'application est composée de plusieurs pages statiques et dynamiques avec une interface responsive et ergonomique. Les données sont récupérées au format JSON via des requêtes AJAX, puis affichées dynamiquement sans rechargement de la page.

APIs Publiques Utilisées

OpenWeatherMap
wttr.in

Récupération des données météorologiques en temps réel : température, humidité, conditions climatiques, prévisions sur plusieurs jours.

Météo Gratuit
RandomUser API
randomuser.me

Génération de profils utilisateurs fictifs avec photos, noms, emails, localisations pour affichage dans des tableaux interactifs.

Utilisateurs Gratuit
REST Countries
restcountries.com

Informations détaillées sur les pays du monde : drapeaux, population, capitales, régions, devises et bien plus.

Pays Gratuit
Open Food Facts
openfoodfacts.org

Base de données collaborative sur les produits alimentaires : ingrédients, valeurs nutritionnelles, nutri-score.

Alimentation Gratuit
Zippopotam
zippopotam.us

Informations géographiques basées sur les codes postaux : villes, régions, coordonnées GPS pour plusieurs pays.

Géolocalisation Gratuit
TMDB API
themoviedb.org

Base de données de films et séries : titres, genres, notes, synopsis, affiches et informations sur les acteurs.

Films Gratuit

Fonctionnalités Principales

Récupération Dynamique

Les données sont récupérées en temps réel via des appels AJAX aux APIs publiques, sans rechargement de page.

Tableaux Interactifs

Utilisation de DataTables pour afficher les données avec recherche, tri et pagination intégrés.

Visualisation Graphique

Création de graphiques dynamiques (barres, circulaires, lignes) pour visualiser les statistiques des données.

Interface Responsive

Design adaptatif pour tous les écrans grâce au système de grille de Bootstrap 5.

Validation de Formulaires

Validation JavaScript complète des champs obligatoires, formats d'email, longueurs minimales.

Gestion des Erreurs

Affichage de messages de chargement et gestion élégante des erreurs de connexion aux APIs.
